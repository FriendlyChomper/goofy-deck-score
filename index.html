Goofy Deck Scores

What is this?

This is the goofy method I came up with to try to find decks that won a run but with fewer resources available. It's completely arbitrary with the amount of weight you put on each resource, so I thought I'd come up with a little tool to let anyone do whatever scores they want.

Just to be clear, this doesn't really show anything. It's just a neat way for me to find decks that have strong synergy or combos. They'll need to have that if we're putting a price on resources the deck needed to get there.

Once you've picked some scores you like, the tool will show the runs in order of the lowest scores found. Adjust as you like!
